### Route A: with the Roster Updater (try this first)
1. Open the roster COPY and `Roster Updater.xlsm` in the SAME Excel window (open the roster from its folder first, then File > Open the updater). Press Ctrl+S in the roster. Click the roster so it is in front.
2. Alt+F8 > `'Roster Updater.xlsm'!CheckUpdateFolder` > pick the unzipped `Callout_Roster_v24.3.1` folder. Nothing changes. It should list **0 new** and the rest "to replace".
3. Alt+F8 > `'Roster Updater.xlsm'!UpdateFromFolder` > same folder > OK. It saves a backup copy, swaps the code and stops. Nothing is saved yet.
4. Alt+F11, click the ROSTER's project on the left, **Debug > Compile VBAProject**.
   - No message: Alt+F8 > `UpdateFinished` > Yes. It saves.
   - A message: note the line it highlights, Alt+F8 > `UpdateDrop` (puts the old code back). Send me the line. Do not press Ctrl+S in between.
5. Close the roster and open it again. Go to Part 2.

If the updater says "No roster is open": **take a photo of that box** (it lists what Excel can see, and I still owe an explanation for the v2 miss), then close both files and use Route B.

### Route B: by hand

Re-paste **ThisWorkbook and all nine forms** (only their version line changed, but SystemCheck checks it): for each of ThisWorkbook, frmOvertimeEntry, frmPostingEntry, frmNewPosting, frmShiftSwitch, frmTimeOff, frmLeave, frmSickCall, frmConvert, frmEmployee: right-click > View Code, Ctrl+A, paste the file of the same name from `paste-in/`.
