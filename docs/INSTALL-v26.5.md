# Call Out Roster v26.5 - install (the Install panel)

The first revisions after the beta build: Graeme's five changes from the v26 testing (Oct 19), the masked month PDF from the v26 reviews, and the Kronos export read directly. Brief: `briefs/v26.5.md` (the decisions inside). **One item changes a rule** (Refused counts the pay periods up to the current one); see below.

Needs **v26 installed** and **Roster Updater.xlsm v4.1**. **The updater does not change.** The panel's swap replaces every module (all 25 stamps on v26.5; no new module), **re-pastes ThisWorkbook and frmEmployee** (the roster double-click; the Edit mode), and **rebuilds the members' template** (Members M3.1: a new data sheet). SelfTest gains one suite (refthrough): 649 cases, 75 suites. **SmokeTest is 20 steps** (step 10 = the Employee pop-up's Edit; the later steps moved up one).

**Back up first. Do it on a copy before the real roster.** Group 3 runs `ApplyRosterLayout` and then **`RefreshRosterFormulas`** (the new Refused formula on every row: until it has run, IntegrityCheck shows one Check line saying to run it, never a PROBLEM for that).

## What's new
- **Nothing on the roster is typed into any more (item 1).** The cells an admin could type into (home unit, crew, phone, worked, seniority, email, the unit codes) are locked in every view. **Double-click a person's row** (or click it and press Employee): the Employee pop-up opens on **Edit** with their details; change what you need and SAVE CHANGES. The box lists every change first; code changes go in the Grade Log, a crew change is dated into the crew history, and nobody's hours move. **Worked hours come from the Kronos import only** (the Excel export).
- **Refused counts the pay periods up to the current one (item 2; a rule change).** A posting's refusal charges always carried the shift's pay period; now Refused (I) and Total Hours (G) count only the periods up to the current one, so a refusal for a shift two periods out shows in its column but starts counting when that period begins. Call-outs carry the call-out date's period, nothing changes for them; provisional accepted OT counts as before. The status bar's split, the Refusals Report's "1-current" default, the members' figures and IntegrityCheck follow. The hidden name `RefusedThrough` holds the current period's start; it moves on every open.
- **The short flag counts every unit (item 3).** The calendar's "N short" flag and Needs Attention's BELOW MINIMUM STAFFING cover every unit with a minimum, whatever unit group is picked.
- **My history's pay-period block (item 4a):** Charged hours, Posting refusals, Call-out refusals, and **Worked (Kronos)** per pay period (a dash until an export has been imported). The master's member-safe history report matches it.
- **Premium hours per pay period from the Kronos export (item 4b).** `Import Kronos` now reads the export itself ("Employee Transactions and Totals": one dated row per transaction) when it is given one: Worked (H) is the sum of the premium pay codes per person as before, and a **Worked Periods** sheet (admin) holds each person's premium hours per roster pay period, rebuilt at every import. Point `KRONOS_PATH` at the export file, or at the **folder** the exports are saved in (ending in `\`): the newest file is read. The pivot workbook ("Sorted Data Here") still works as the fall-back but gives no per-period figures.
- **Electronic sign-ups are ON (item 5).** The members' file shows Sign me up / Withdraw on open postings; a click drops a request file into the `Signups` folder beside the members' file (made at the next publish; members need write access to it); the Award pop-up pre-ticks them at LOAD and names late ones, withdrawals and unknown names. The supervisor's tick is what counts; the paper sheet stays valid.
- **The printed month calendar is the members' copy (item 0).** Print / PDF on the Calendar draws it masked (a sick call or a personal day reads Off; a line with a leave word is not printed as written), exports, then redraws for supervisors.

## The panel
1. Open the roster (ADMIN view), then File > Open `Roster Updater.xlsm` in the same Excel window. Click the roster so it is in front.
2. Alt+F8 > `'Roster Updater.xlsm'!InstallPanel`. Pick the unzipped `Callout_Roster_v26.5` folder.
3. Click the one blue button, read its box, click the next. Group 3: the bar rebuild, **RefreshRosterFormulas**, System check ("25 of 25 on v26.5", ThisWorkbook v26.5, frmEmployee v26.5), Self test (649 / 75), the members' template rebuilt, `KRONOS_PATH`. Group 4: the practice copy + SmokeTest (20 steps), the Edit pop-up, a future-period refusal, the short flag with another group picked, the masked month PDF, Sign me up from the members' file and the LOAD summary, the Kronos export import (on the copy), the members' file's new columns.

By hand instead: remove and import the 25 modules, re-paste ThisWorkbook and frmEmployee from `paste-in/`, Debug > Compile, Alt+F8 > ApplyRosterLayout, Alt+F8 > RefreshRosterFormulas; open the members' TEMPLATE, Remove + Import `member/modMember.bas` (its ThisWorkbook did not change since M3), Compile, Alt+F8 > BuildMemberTemplate, Save; then the group 3-4 rows yourself.
