## Decided Oct 19, after the reviews (Graeme, recommended options taken)
1. **One rule for call-outs and postings:** a charge carries the pay period of the shift it was for and counts in Refused / Total Hours once that period starts. A call-out logged for a shift in a later period defers the same way (rare: call-outs are mostly same-day). No code change.
2. **Sign-up request files:** named with the Windows login, in the Signups folder every member can list - accepted for the beta (the paper sheet shows who signed up too). Revisit if anyone objects: an access rule on the folder (then Sent / Withdraw can't read it back) or files named by posting + a random id (a v26.5.5 change).
3. **`KRONOS_PATH` = the folder the exports are saved in** (ending in a backslash; exports only; the newest file is read). A single file name still works.
