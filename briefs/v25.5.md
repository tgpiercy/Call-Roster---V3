## Checked against the code (Oct 18)
- **The call-out pop-up (`frmOvertimeEntry`) is built in code.** Only seven controls come from the designer (`btnLoad`, `btnSubmit`, `btnAccepted`, `btnRefused`, `btnLeftMsg`, `btnUnavailable`, `lstEmployees`; `forms/control-manifest.txt`), and `UserForm_Initialize` sets even their positions and sizes (`StyleOutcome`, the `With btnLoad` / `btnSubmit` blocks). Every label, combo, box and the partial-hours button is made by `MakeLabel` / `MakeCombo` / `MakeBox` / `Controls.Add`. So the rework is a paste-in change (`paste-in/frmOvertimeEntry.txt`, re-pasted at install, `FORM_RELEASES` bumped); the designer file is not touched.
- **What the form does today, in order:** unit / Days-Nights / crew / date / hours, LOAD LIST (`LoadEligible` + `FilterNotFree`, the Kronos-age warning once, the switch flags), the list (name, phone, total with `*` / `~`, outcome), "Now calling" (name, code, hours with the provisional / estimate notes, the grade note, the S/S note) and the phone at 16 pt, the unavailable-reason combo, four outcome buttons at 9 pt (46 pt tall) plus ACCEPTED PART OF THE HOURS at 8 pt, the progress line, SUBMIT ALL ENTRIES, a status line at 8 pt; `RecordOutcome` moves to the next unlogged person; `ShiftClosedByPartial` refuses any outcome after a partial (D-E4); submit = `SubmitCalloutSession` then a MsgBox with the long summary; close warns about unsaved entries. The form is 445 x 538 pt.
- **Scale:** every size is a literal in `Initialize`; a `UI_SCALE` factor multiplies Left / Top / Width / Height and Font.Size in the four helpers and the designer blocks - one mechanical pass per form (the proposal's step 2).
- **Keyboard:** a UserForm gets `KeyDown` only when a control that passes keys has the focus; the ListBox does (`lstEmployees_KeyDown`), so the letters are handled there and the list keeps the focus after every outcome (`SetFocus`).
- **The Desk / the panel:** "Fill a shift now" opens it empty; the sick call pre-fills it (`Prefill`); the Install panel's `SmokeCallout(unit, d, shift)` opens it pre-filled for the hand check, so the new look is checked on the plant PC.
