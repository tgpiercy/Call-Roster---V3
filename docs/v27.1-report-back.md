## Tooling built (commits 60dbfd3, b292ddd; tests only, nothing ships)
- **`tests/movecheck.py <old ref>`**: proves a split is pure movement. Every procedure exists exactly once afterwards, with a body identical except Private -> Public on its header and a module qualifier that follows the move. Every module-level declaration exists exactly once, word for word, except Private / Dim -> Public. Every other file is identical except for qualifiers. A **SCOPE** pass fails anything that reaches a Private name of another module, a `Module.Name` the module doesn't have, or a Public signature that uses a Private Type.
- **`tests/splitmodule.py ROOT FROM NEW=a-b[,c-d] ...`**: the move, made by script. It cuts whole line ranges (numbered against the original file) into new modules, writes CRLF, and refuses a range that cuts a procedure. Builders run it, commit it with the move, and a reviewer can re-run it.
- **callcheck gains three checks:**
  - **DUPPUBLIC**: the same Public name in two standard modules. It counts variables, Consts, Types and Declares; vbacheck saw only procedures and Consts.
  - **QUALREF**: `Module.Name` in code that names nothing in that module, or names something Private there.
  - **MACROSTR**: now also flags a `"modX.Name"` string whose module doesn't exist.
- **`tests/snapshot/modSnapshot.bas`** (test-only; never in `modules/`, so never zipped or counted):
  - **TakeSnapshot** draws the Calendar (this month, every named group), Needs Attention, the Board, the newest posting's sheet, the call-out roster and the Desk. It writes a hash per row (value plus every format), per sheet's column widths and per shape (place, fill, text, macro) to `snapshot-<release>.txt`. The file holds hashes and sheet / shape names only.
  - **CompareSnapshots** compares the two newest files.
  - It refuses the live roster, and it masks the digits of clock text ("Drawn ...", "printed ...", "updated ...", "N days old / ago") and every digit on the Desk.
  - `tests/test_snapshot.py` proves it imports clean against `modules/`.

## Things the maps show that change the plan
1. **N_MODULES goes 30 -> 41, not 40.** The proposal has 11 new modules: 5 from the calendar, 3 from people, 3 from postings.
2. **Three rule gaps were found while reading.** I re-read each one in the code; they are real. None can be fixed in a behaviour-free release.
   - **A same-day two-way switch never runs the 16 h check** (modShiftSwitch.bas:489-497 clears the stops and never calls FatigueStop). CLAUDE.md says every switch must fit.
   - **A missed morning's Kronos day can count twice in Worked Periods** (published as dWorked):
     - the year-to-date report logs it as an edit, dated at its Through date (ImportKronosData.bas:1340-1354);
     - the late one-day report then counts it again (1469-1499), because the exclusion only looks at the edit's own date.
     - H itself is right.
   - **Staffing count edges.** A switch saved over the "isn't on that shift" warning counts the worker without counting the giver off. Two partial lines round up separately. An empty " / " part counts a person.
3. **modCalendar is still 3,877 lines** after the split. DrawCalendar stays the biggest piece until wave 2.
4. **The Desk preview changes the admin Desk by one button.** The snapshot run as admin will show that one shape as different, which is expected. The button goes at the end of the footer row, so no other shape moves.
5. **CLAUDE.md still lists the obsolete SumTransactionsCore**; fixed at integration.

## Desk preview (design)
- **The button.** A footer button on the admin Desk, "See the supervisor Desk", runs `DeskPreview` (RequireAdmin).
- **The flag.** It sets a session-only flag in modDesk and redraws the Desk. DrawDesk's three admin choices (lines 174, 176, 209: the Kronos pill text, the admin tiles, the supervisor layout) read `gAdminUnlocked And Not mPreview`.
- **The banner.** The preview carries a band, "PREVIEW - the Desk a supervisor sees", and a "Back to my Desk" button. Nothing else in the view, the tabs or the bar changes.
- **Rights.** A supervisor never sees the button. The flag lives only in memory: it is gone when the file reopens, and "Back to my Desk" turns it off. Run from Alt+F8 on another sheet, it brings the Desk forward. (As built: ApplyView does not clear it; the PREVIEW pill shows whenever it is on.)
- **Open:** whether the preview's job buttons work, or only show.
