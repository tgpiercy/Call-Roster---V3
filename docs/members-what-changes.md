# What changes for you - the members' file at go-live (v29 / Members M6)

For the operators who use **Call Out Roster - Members.xlsm**. One page; the roster itself is unchanged for you.

## Where the file is
From the cutover (the week of Jan 11-15, 2027) the members' file lives in the **members' folder** on P: (the supervisors will tell you the path and pin a shortcut on the control-room PCs). Open it from there. The old copy beside the supervisors' roster is gone; a shortcut that still points there will not open.

## What the file does (as before)
- **Who's next** - the call order for every unit, today and ahead, and who is not free and why.
- **Postings** - what is posted, who signed up, and **SIGN UP** from the file (one click; the supervisor's tick on the paper sheet still counts).
- **My history** - what you were charged, worked and refused, by pay period, for any name.
- **Requests** (since M5) - ask for **time off** or a **switch** (the partner clicks **Agree** on their own PC first); **My requests** shows where each one stands; **Withdraw** while it waits.

## What is new
- **My history's PDF** saves into your own **Downloads** folder (the members' folder is read-only for you). Print it from there if you want paper.
- A request whose booking the admin later took back reads **Booking voided** under My requests - ask the admin why.
- The two folders the file writes into, **Signups** and **Requests**, sit beside it in the members' folder. You can read and write there; nothing else in the folder can be changed by you.

## What stays the same
- Sick days and personal days show as **Off**; leave shows as **Leave**. Nobody's phone, email or reasons are in the file.
- The file is refreshed when a supervisor publishes it (the time is at the top). It never changes by itself.
- Paper stays on hand for two pay periods after the cutover.

## If the file will not open or looks old
Tell the shift supervisor. The roster is the record; the file is a window on it.
